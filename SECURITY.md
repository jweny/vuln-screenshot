# Security policy

## Supported versions

Security fixes are provided for the latest released minor version.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/jweny/vuln-screenshot/security/advisories/new). If it is temporarily unavailable, use a private contact method listed on the [maintainer's GitHub profile](https://github.com/jweny). Do not open a public issue with exploit details, credentials, captured traffic, or command output.

Include the affected version, operating system, reproduction steps, impact, and any proposed mitigation. You should receive an initial response within seven days.

## Sensitive output

This project intentionally preserves raw HTTP messages and terminal output. Evidence bundles can therefore contain credentials, cookies, API keys, source code, local paths, and other sensitive data. Store bundles in a protected location and review screenshots before sharing them.
